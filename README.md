# Лабораторна робота №6

## Створення масиву C

Масив C формується на основі масиву A, який містить 12 цілих чисел.

Програма знаходить другий непарний елемент масиву A. Починаючи з елемента, наступного за другим непарним числом, усі наступні елементи діляться на значення другого непарного числа.

Якщо в масиві менше двох непарних чисел, відповідне перетворення не виконується.

У результаті програма виводить початковий масив A та сформований масив C.
